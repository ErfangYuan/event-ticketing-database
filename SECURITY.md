# Configuration and reporting

This is an independently configured portfolio distribution. It contains no inherited service credentials, deployed accounts, session files or automatic deployment workflows. Copy the environment template and configure your own services. Keep all private material in ignored local files or a secret manager.

Do not put secrets or private documents in an issue. Report a reproducible problem using synthetic data, redacted logs and the affected version. Provider keys exposed outside their intended scope must be rotated at that provider; deleting a local file does not revoke a credential.
